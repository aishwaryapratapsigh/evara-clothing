# 🛍️ Evara Clothing – React Ecommerce App

A modern and responsive **Ecommerce Web App** built with **React + Vite**.  
It provides users with features like product browsing, wishlist management, shopping cart, and authentication pages.

---

## 🚀 Features
- ✅ Responsive UI with **Bootstrap & custom CSS**  
- ✅ **Product listing** with categories  
- ✅ **Search functionality**  
- ✅ **Wishlist & Add to Cart** pages  
- ✅ **Profile Login & Signup** pages  
- ✅ Reusable components (Navbar, Hero Section, Product Cards, Trending Section, Footer)  
- ✅ **Deployed on GitHub Pages**

---

## 🛠️ Tech Stack
- **Frontend:** React, Vite  
- **UI Library:** Bootstrap 5  
- **Routing:** React Router  
- **Deployment:** gh-pages (GitHub Pages)
